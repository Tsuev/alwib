# 🎨 Admin Dashboard Layout

## Описание

Полноценный каркас админ-панели (workspace) с современным дизайном в стиле macOS. Включает:

### 📦 Компоненты

#### 1. **Header** (`src/components/app/Header.vue`)
Верхняя панель с:
- **Слева**: Кнопка для переключения sidebar
- **По центру**: Часы реального времени и баланс пользователя
- **Справа**: 
  - Профиль пользователя с меню (Профиль → Настройки → Выход)
  - Кнопка уведомлений с индикатором
  - Кнопка настроек

#### 2. **Sidebar** (`src/components/app/Sidebar.vue`)
Боковое меню с:
- Logo секция (Alwib Workspace)
- Навигация (Главная)
- Модули (VPN, ИИ-ассистенты, Загрузчик)
- Сервисы (скоро)
- Кнопка выхода

**Особенность**: Активная кнопка подсвечивается в зависимости от текущего маршрута

#### 3. **AdminLayout** (`src/layouts/AdminLayout.vue`)
Основной лейаут, который:
- Комбинирует Header и Sidebar
- Управляет видимостью sidebar
- Предоставляет контент-зону

### 🎯 Фичи

✅ **Активный маршрут** - Кнопки меню автоматически активируются при переходе на маршрут
✅ **macOS стиль** - Glassmorphism, градиенты, минималистичный дизайн
✅ **Отзывчивый дизайн** - Полностью адаптивен для мобильных устройств
✅ **Dark tema** - Тёмная тема по умолчанию
✅ **PrimeVue компоненты** - Меню, Avatar, Button, Sidebar из PrimeVue

### 📂 Структура файлов

```
src/
├── components/
│   └── app/
│       ├── Header.vue       # Верхняя панель
│       └── Sidebar.vue      # Боковое меню
├── layouts/
│   ├── DefaultLayout.vue    # Используется в views
│   └── AdminLayout.vue      # Основной лейаут приложения
├── views/
│   └── HomeView.vue         # Главная страница с дашбордом
├── stores/
│   └── uiStore.ts           # Состояние sidebar
└── App.vue                  # Корневой компонент
```

### 🚀 Использование

1. **В App.vue**:
   ```vue
   <AdminLayout>
     <RouterView />
   </AdminLayout>
   ```

2. **Автоматически работает**:
   - Header отображается всегда (кроме /auth и /preload)
   - Sidebar отображается только для авторизованных пользователей
   - Маршруты автоматически активируются

### 🎨 Стили

- **Framework**: TailwindCSS 4.0
- **UI Library**: PrimeVue 4.3
- **Icons**: PrimeIcons 7.0
- **Color scheme**: Slate (950-900) с accents Primary-400

### 💡 Примеры маршрутов

```
/              → Home (Главная)
/vpn           → VPN модуль
/ai            → ИИ ассистенты
/downloader    → Загрузчик
/auth          → Авторизация (без layout)
/preload       → Загрузка (без layout)
```

### 🔧 Кастомизация

**Добавить новый модуль в sidebar**:
1. Добавьте маршрут в `router/index.ts`
2. Добавьте пункт меню в `components/app/Sidebar.vue`
3. Функция `isRouteActive()` автоматически активирует его

**Изменить данные Header**:
- Баланс: `balance` в `Header.vue`
- Username: берётся из `userStore`
- Время: обновляется каждую минуту

### 📱 Отзывчивость

- **Desktop**: Sidebar видна, полная ширина 260px
- **Tablet**: Sidebar схлопывается
- **Mobile**: Sidebar становится модальным окном
